# plumber-training

Dépôt de formation [Plumber](https://getplumber.io). Ses workflows GitHub Actions contiennent **volontairement** de mauvaises pratiques de sécurité CI/CD : ne pas les copier en production.

## Mission

1. **Use this template** > créez votre propre dépôt (public).
2. Ajoutez l'Action Plumber et lisez votre score.
3. Corrigez les workflows jusqu'à obtenir la note **A**.

Le guide pas à pas est partagé pendant la session.
